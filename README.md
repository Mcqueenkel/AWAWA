# AWAWA

A modified build of Hachimi Edge, the game mod for UM:PD. Windows, Steam version only.

## Download and install

1. Close the game.
2. Download `cri_mana_vpx.dll` from the [latest release](https://github.com/Mcqueenkel/AWAWA/releases/latest). If your browser warns about the file, choose **Keep**.
3. In Steam, right-click the game, then **Manage** → **Browse local files**. This opens the game folder.
4. Put `cri_mana_vpx.dll` in that folder, next to the game's `.exe` (not in a subfolder).
5. Start the game from Steam. Press the **Right Arrow** key in game to open the menu.

Already using Hachimi Edge or another Hachimi-based mod? Uninstall it first. Two copies at once will conflict.

## Update

Close the game and replace `cri_mana_vpx.dll` in the game folder with the one from the newest release.

## Uninstall

Close the game and delete `cri_mana_vpx.dll` from the game folder. To also remove settings, delete the `hachimi` folder next to it.
